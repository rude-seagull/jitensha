# Jitensha 自転車

**« Apprends la mécanique vélo, de zéro à héros. »**

Jitensha is a free, extremely detailed, interactive bicycle mechanic course in French — taking a total beginner to home-mechanic-pro level, across every kind of bike: city, road, MTB, e-bikes, bikepacking rigs, fixies, and exotic builds.

It ships as a fully static website: Astro + Markdown, vanilla JS, `localStorage` for progress. No accounts, no tracking, no server. KISS.
